Permission prompts

When the app a task is using asks for a permission ("Allow Kalshi to use your location?"), the agent answers by these settings with no prompt: by default "Only this time" (or the narrowest grant the dialog offers), notifications allowed, location approximate. Never "Allow all the time". Another app's request asks you on the phone. Allowing more (While using the app, Precise) needs your approval on that phone, with its screen lock; tightening is immediate.
