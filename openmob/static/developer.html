Limits & pricing

Tiers

credits per step

A step is one action on the phone. A task costs steps × its tier's rate; one cancelled before it starts costs nothing.

API keys

Keys act as your account on your own phones, over REST and MCP. Send one as Authorization: Bearer om_live_…, keep it in an environment variable, and never commit it.

Webhooks

Get a signed POST when a task finishes or needs you, instead of polling.

Endpoint

Not set

Must be a public https:// URL. Saving it again makes a new signing secret.

Events

task.finished
succeeded, failed or cancelled
task.needs_input
asked a question
task.needs_confirmation
waiting for approval
orchestration.finished
a multi-phone run ended

The body is {"type", "created", "task"}, where task is the same object as GET /v1/tasks/{id}; for orchestration.finished it has orchestration (as GET /v1/orchestrations/{id}) instead of task, so check type first. Failed deliveries are retried for about an hour with the same X-OpenMob-Delivery id, so drop ids you've seen. Answer 2xx fast, then do the work.

Verify the signature

Each request carries X-OpenMob-Signature: t=…,v1=…: the hex HMAC-SHA256 of "{t}.{raw body}" with your signing secret. Reject a t older than 5 minutes.

Full details: Webhooks docs.
