Connect a phone

Any Android phone (Android 11+) can join this agent. No cable, no developer mode.

  1. Scan the QR codeIt opens a page on the phone with everything below.
  2. Install the OpenMob appDownload it from that page and allow the install.
  3. Open the app from that pageIt arrives already paired with this server.
  4. Turn on OpenMob in Accessibility, then tap ConnectThis lets the agent see the screen and tap. Disconnect any time from the notification.
